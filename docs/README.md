# Documentation

Use this directory for durable project documentation. Temporary research and generated statistics belong in `work/`, not here.

| Document | Use it when… |
| --- | --- |
| [Architecture](ARCHITECTURE.md) | You need to understand the site, data flow, narration, or directory boundaries. |
| [Content Workflow](CONTENT_WORKFLOW.md) | You are selecting a video, writing a briefing, or reviewing editorial quality. |
| [Operations](OPERATIONS.md) | You are refreshing the catalog, testing audio, or publishing the site. |

Keep the root `README.md` concise enough for a new contributor. Put implementation detail and checklists in these documents, and link back to them rather than duplicating instructions.
